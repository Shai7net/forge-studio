# Hebrew UI glossary

Style: short, clear, friendly Hebrew; buttons in the imperative (צור, שמור, טען); explanations as neutral sentences
(infinitive or noun phrases, no gendered "you"). Technical terms people search for keep the English term in
parentheses on labels: `צעדי דגימה`, `מספר התחלה (Seed)`. Model, sampler, file and extension names are never
translated. Code, schedules like `0: (1.0)`, units and placeholders stay exactly as they are.
